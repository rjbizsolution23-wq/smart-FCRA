Icon Export Checklist

Ship these 6 files to /public/icons/

  • favicon-16.png — 16 × 16, browser tab
  • favicon-32.png — 32 × 32, browser tab retina
  • apple-touch-icon.png — 180 × 180, iOS home screen
  • icon-192.png — 192 × 192, Android PWA
  • icon-512.png — 512 × 512, PWA install prompt
  • icon-maskable-512.png — 512 × 512 with safe zone (Android adaptive)

Source: use the RJ logo JPEG. Convert to PNG with rounded corners at each size. Maskable icon needs 10% padding on all sides for Android's adaptive shape.
