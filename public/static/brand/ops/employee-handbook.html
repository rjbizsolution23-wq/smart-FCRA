● Chapter 01

The Culture Manifesto.

Seven principles. Non-negotiable. If you're on the team, this is how we think.

1

Systems > Slogans

We don't sell templates. We build systems. Every deliverable ships as infrastructure — not a slide, not a slogan, not a promise.

2

Build for the Founder Who Can't Sleep

Every system we ship should let a founder rest at night. If our work doesn't reduce someone's stress, we're not done yet.

3

Response Time is a Feature

Client Slack: 4 business hours. Internal Slack: same-day. Nobody waits alone. Silence is a bug we treat as high-priority.

4

Compliance is the Foundation

Automation without guardrails is a lawsuit. Every system we build ships with FCRA, FDCPA, and TCPA-informed workflows by default.

5

Delegated Access Only

We never ask a client for passwords, 2FA codes, or recovery phrases. Ever. Role-based permissions or password-manager sharing, always.

6

Ship > Perfect

7-day launches are our default because "shipped and iterating" beats "perfect and unlaunched" every time. Momentum compounds.

7

Write it Down

If it's not in a doc, it didn't happen. Every decision, every client agreement, every system change goes into writing. Memory doesn't scale.
