## 🛠 HOW TO USE THIS LIBRARY

**Print files** (Letterhead, Invoice, Business Cards, Envelope, Folder, Proposal, Contract Cover, Rate Card, Case Study, One-Pager, Growth Playbook, Whitepaper, Annual Report, Financial Model, Cap Table, Term Sheet, Vesting Agreement, Operating Agreement, NDA, Dispute Letter, Credit Report, Certificate, Holiday Cards, Envelope, Folder):
→ Open the HTML → **Cmd/Ctrl + P** → Destination "Save as PDF" → margins **None** → send to printer.

**Interactive prototypes** (Landing Page, Dashboard, Brand Kit, Asset Pack, Meet Rick, Team+Careers, Utility Pages):
→ Recreate as real routes in Next.js / any modern framework. See `16 · Developer & Backend/DEVELOPER-HANDOFF-README.md`.

**Interactive forms** (14 · Interactive Forms/):
→ Open in browser → they work standalone with localStorage auto-save.
→ Production deploy: wire the POST endpoints to Cloudflare Workers per `16 · Developer & Backend/CLOUDFLARE-BACKEND.md`.

**Social/image surfaces** (all social kits, thumbnails, ads, backgrounds, wallpapers, merch mockups):
→ Right-click → "Save image" (or screenshot at 100% zoom).
→ Or: headless-Chromium capture pipeline via `page.screenshot()` at the source viewport size.

**Email templates** (Email Header, Email Signature, Email Newsletter, Email Drip):
→ Copy the inner table markup → drop into Mailchimp / ConvertKit / Klaviyo / GoHighLevel HTML editor.
